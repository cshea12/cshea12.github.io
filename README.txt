Job Tracker informational website for GitHub Pages
==================================================

Files to upload to your PUBLIC GitHub Pages repository:
- index.html
- privacy.html
- style.css

1. Create repository named cshea12.github.io on GitHub (Public).
2. Upload these three files to the repository root and commit.
3. In Settings > Pages, select Deploy from a branch, branch main, / (root), and Save.
4. After deployment check https://cshea12.github.io/ and https://cshea12.github.io/privacy.html.

IMPORTANT:
- This is only the public informational website; never upload your Python project's credentials.json, token.json, data/*.db, application data, or .env files.
- Google OAuth Authorized Domains may not accept a github.io subdomain, even if Search Console verifies URL-prefix ownership. Do not assume this website alone guarantees Google OAuth publishing. If Google says "Domain not found" for cshea12.github.io, a separately registered domain you control may be needed.
- Review the privacy policy against your real app implementation if you make changes.
