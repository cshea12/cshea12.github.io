Privacy Policy

Last updated: October 31, 2026

Job Tracker is a personal-use Python automation project. It helps the account owner track job applications and hiring updates from Gmail in a local database and a Google Sheets spreadsheet. It is not a public service for other users.

Google data accessed

When the owner grants permission, the locally running tool accesses Gmail messages to identify application confirmations, rejections, interview invitations, assessments, and related recruiting correspondence. It also uses Google Sheets access to update the owner's chosen spreadsheet with application summaries.

How data is used

Message content is processed to identify employer names, job titles, and application events. The tool stores structured application records and email metadata such as message identifiers, timestamps, sender, subject, snippet, classifications, and status history in a local SQLite database. It does not intentionally store full Gmail message bodies in that database. Application summaries, including company names, job titles, dates, statuses, and notes, can be written to the owner's Google Sheet.

Where information is stored

The Python application and its SQLite database run on the owner's own computer. Google OAuth credentials and tokens are stored locally for authorized access. Application summaries synchronized to Google Sheets are stored in the owner's Google account and are governed by Google's applicable terms and privacy practices.

The public website you are reading is hosted with GitHub Pages. It does not connect to Gmail, collect messages, or provide a sign-in form.

Sharing and advertising

Job Tracker does not sell Google user data or use it for advertising. The local application sends only the information needed to Google's APIs for the requested Gmail access and Sheets synchronization. There is no separate commercial email-data service or marketing analytics built into this website.

Access, retention, and deletion

The owner can stop automated execution at any time, revoke access through their Google Account's third-party connections, delete locally stored credentials and database files, or remove application data from their Google Sheet. Removing a local token does not itself delete data already synced to Sheets.

Security

OAuth authorization is used instead of storing a Gmail password. Credentials, token files, and the local application database are not part of this public informational website and should never be uploaded to a public source-code repository.

Changes and questions

This policy may be revised if the project's data handling changes. For project information, see the maintainer's GitHub profile.
