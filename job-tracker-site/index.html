Personal Python automation project

Job applications, organized automatically.

Job Tracker helps organize application confirmations, interview invitations, assessments, and hiring decisions from a connected Gmail account in one place.

Runs locally · Private-use project

How it works

After the account owner authorizes Google access, Job Tracker scans job-related email messages, classifies recruiting events, matches them to applications, and organizes the results in a local SQLite database. A separate sync step publishes application summaries to a Google Sheet controlled by the account owner.

01 · Find

Reads authorized Gmail messages to locate job application and recruiting correspondence.

02 · Organize

Tracks positions and status changes in a local SQLite database with safeguards for uncertain matches.

03 · Sync

Updates the owner's Google Sheets application tracker with company, position, status, and related details.

Built for personal use

This is a personal automation and learning project, not a public application or hosted service. The Python application runs on the owner's computer. This website provides information about the tool and does not ask visitors to connect Google accounts or upload email data.

Privacy by design: Job Tracker processes email content to identify events, but the local database stores message metadata and classification results rather than complete email bodies. Details about access, storage, and control are explained in the Privacy Policy.

Technologies

Python · Gmail API · OAuth 2.0 · SQLite · Google Sheets API · Windows Task Scheduler · WSL2 Debian
